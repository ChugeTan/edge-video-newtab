# 商店文案（简体中文）

> 用途：Microsoft Partner Center → Microsoft Edge 加载项 → 商店列表。以下内容可直接复制粘贴。

## 扩展名称
视频新标签页

## 简短描述（≤132 字符）
把 Edge 新标签页变成可自由更换视频的沉浸式背景：WebGL 液态玻璃搜索框、本地视频/直链、播放列表、随机轮换。

## 详细描述
把 Edge 新标签页变成你的私人影院。

视频新标签页会用一段循环播放的视频替代默认新标签页背景，并配上一块实时渲染的「液态玻璃」搜索框——磨砂、边缘折射、色散都可以自己调。

主要功能
• 视频背景：内置示例视频，也可以添加本地视频文件（直接拖进页面即可）或视频直链。
• 播放列表：管理多个视频，支持上一个 / 下一个、随机播放与自动轮换（1～60 分钟）。
• 液态玻璃搜索框：WebGL 实时渲染的磨砂、边缘透镜折射与色散；5 个滑杆可调：磨砂强度、玻璃浓度、边缘折射、镜片厚度、色散。
• 页面元素：时钟、日期、搜索框均可显示 / 隐藏；支持 Bing、百度、Google 搜索引擎。
• 播放控制：右上角玻璃菜单可切换视频、静音 / 开启声音；音量、播放速度、画面填充方式可调。
• 完全本地：视频文件只保存在本机 Edge 扩展存储中，不会上传到任何服务器；扩展本身不收集任何数据。

使用方式
1. 安装后按 Ctrl+T 打开新标签页，即可看到视频背景。
2. 点击右上角「≡」菜单 → 设置，可更换背景视频、调整玻璃效果与页面元素。
3. 也可以把本地视频文件直接拖进新标签页，或粘贴视频直链。

说明
• 推荐使用 MP4（H.264）或 WebM 格式的视频。
• 液态玻璃效果需要 WebGL 支持；不可用时会自动回退为普通毛玻璃。
• 所有设置与视频仅保存在本机；卸载扩展即会删除。
