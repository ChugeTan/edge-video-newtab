# 微软 Edge 加载项商店 · 提交指南

> 准备工作已全部完成：发行包（zip）、商店文案、截图、宣传图、隐私政策都在本文件夹里。
> 你只需要一个 Microsoft 账号，然后按下面的步骤在 Partner Center 完成提交。

---

## 第 0 步：注册开发者账号（一次性，免费）

1. 打开 <https://partner.microsoft.com/>，用你的 Microsoft 账号登录（没有就注册一个）。
2. 进入 **Microsoft Edge 计划**（Edge program），按提示完成注册。
   - 注册 Edge 扩展开发者是**免费**的（不同于 Chrome 的 $5）；
   - 需要填写"发布者显示名称"（会展示在商店里）、联系邮箱、国家/地区；
   - 可能需要邮箱验证，按提示操作即可。
3. 注册完成后，在 Partner Center 里选择 **Microsoft Edge → 创建新的扩展**。

> 说明：登录、协议确认、账号验证必须由你本人完成（涉及账号与法律条款），我无法代填。

## 第 1 步：上传发行包

- 文件：`视频新标签页-v1.2.0.zip`
- 在"包"页面上传，等待清单（manifest）解析成功。
- 如果提示清单错误，先检查 zip 根目录是否直接包含 `manifest.json`（本包已处理，应无问题）。

## 第 2 步：填写商店列表

打开"商店列表"页面，按以下内容填写（可直接从 `商店文案-中文.md` 复制）：

| 字段 | 填写内容 |
| --- | --- |
| 显示名称 | 视频新标签页 |
| 简短描述 | 见 `商店文案-中文.md`（≤132 字符） |
| 详细描述 | 见 `商店文案-中文.md` |
| 类别 | 娱乐（Fun） |
| 语言 | 中文（简体）；可再添加 English |
| 商店 Logo | `宣传图/商店Logo-300x300.png` |
| 截图 | `截图/` 里 3 张 1280×800（至少 1 张，建议 3 张都传） |
| 小宣传图 | `宣传图/小宣传图-440x280.png` |
| 大宣传图 | `宣传图/大宣传图-1400x560.png` |
| 支持联系邮箱 | **填写你的邮箱**（必填） |
| 网站 / 支持页面 | 可选，有个人主页可以填 |

## 第 3 步：填写属性

- **隐私**：选择"此扩展不收集个人数据"（与 `隐私政策.md` 一致）。
- **权限说明**：`storage` 用于保存用户设置；`unlimitedStorage` 用于在本地保存用户选择的视频文件。均不上传网络。
- **年龄分级**：按问卷如实选择（无用户生成内容、无社交、无广告）。
- **审核测试说明**：复制 `审核测试说明.md` 的内容到"给认证团队的备注 / Notes for certification"。

## 第 4 步：提交审核

- 检查所有必填项后点击 **提交**（Submit）。
- 审核通常需要 **1～7 个工作日**，期间可以在 Partner Center 查看状态。
- 若被驳回：按邮件里的具体原因修改后重新提交即可，常见原因见文末"注意事项"。

## 第 5 步：上线与后续更新

- 审核通过后，扩展会自动上架，你会获得一个公开的商店链接（可以分享给朋友）。
- 以后更新：修改 `manifest.json` 的 `version`（如 1.2.0 → 1.2.1）→ 重新打包 zip → 在 Partner Center 同一扩展下提交"更新"，审核通过后用户会自动更新。

## 注意事项

1. **扩展 ID 会变**：商店版本是新的扩展 ID，与你之前开发者模式安装的版本不共享数据。上架后建议卸载开发者模式版本，再装商店版（之前添加的视频需要重新添加，扩展 ID 不同无法迁移）。
2. **隐私政策 URL**：如果提交表单强制要求填写隐私政策链接，可把 `隐私政策.md` 的内容发布到任意公开网页（例如 GitHub Pages、个人博客、Notion 公开页），把链接填进去即可。
3. **常见驳回原因与我们的规避**：
   - 权限说明不充分 → 已在第 3 步给出说明；
   - 截图与功能不符 → 截图均为真实界面；
   - 描述夸大或含未实现功能 → 文案只描述已有功能；
   - 名称/图标误导 → 名称与图标均为自制；
   - 缺少测试说明 → 已提供 `审核测试说明.md`。
4. **上架免费**，无需付费；商店不向开发者收费。
5. 提交前可以先用另一台电脑/另一个 Edge 配置文件安装 zip 里的扩展再自测一遍（本仓库内的开发者模式版本已验证 40/40 项自动化测试）。
