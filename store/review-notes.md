# 给认证团队的测试说明（Notes for certification）

扩展名称：视频新标签页（Video New Tab）
版本：1.2.0

## 功能概述
本扩展把 Edge 新标签页替换为视频背景 + 实时 WebGL 液态玻璃搜索框，并提供播放列表、时钟/日期、页面元素开关等自定义能力。

## 测试步骤（约 2 分钟）
1. 安装扩展后按 Ctrl+T 打开新标签页，应看到视频背景、时钟/日期与搜索框。
2. 点击右上角「≡」玻璃按钮，弹出二级菜单：上一个视频 / 下一个视频 / 静音 / 设置。
3. 点击「设置」，右侧打开设置面板：
   - 「搜索框玻璃」卡片有 5 个滑杆（磨砂强度、玻璃浓度、边缘折射、镜片厚度、色散），拖动可实时改变搜索框玻璃效果；
   - 可关闭「显示时钟」「显示日期」「显示搜索框」验证页面元素开关。
4. 背景视频：设置面板中可添加本地视频文件（或直接把 mp4 文件拖进页面），也可粘贴视频直链。
5. 静音开关：菜单中「静音 / 开启声音」可切换，图标与文字同步更新。

## 隐私与网络
- 扩展不收集任何数据；自身不发起任何网络请求。
- 仅当用户主动添加视频直链时，浏览器会请求该 URL（用户自行提供）。
- 所有设置与视频只保存在本机：`chrome.storage.local` + 本地 IndexedDB。

## 权限说明
- `storage`：保存用户设置。
- `unlimitedStorage`：在本地保存用户选择的视频文件（视频体积较大）。

## 兼容性
- 液态玻璃由 WebGL 实时渲染；WebGL 不可用时自动回退为 CSS 毛玻璃，功能不受影响。
- 已通过 40 项自动化 UI 测试（新标签页、设置、视频切换、持久化、二级菜单、玻璃渲染等），无 JS 错误。

## 备注
- 扩展不包含远程代码、不做任何远程配置；所有 JS 均打包在扩展内。
- 新标签页覆盖使用标准 `chrome_url_overrides.newtab`，未修改浏览器搜索设置。
