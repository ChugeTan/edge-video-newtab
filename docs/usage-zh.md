# 视频新标签页 · 使用说明

把 Edge 的新标签页变成**可以自由更换视频背景**的沉浸式页面。支持本地视频、视频直链、播放列表、随机播放、自动轮换、静音/音量、画面填充、亮度/模糊/暗化、时钟和搜索框开关等，全部数据只保存在本机。

> 这是本地安装的"未打包扩展"，不联网、无广告、无账号，也不会收集任何数据。

## 一、安装（只需一次，约 1 分钟）

1. 双击运行 **`一键安装.bat`**（或在地址栏打开 `edge://extensions/`）。
2. 在打开的 Edge 扩展管理页**右下角**打开「**开发人员模式**」开关。
3. 点击左上角「**加载解压缩的扩展**」，选择本文件夹里的 **`extension`** 文件夹（里面有 `manifest.json`）。
4. 新建一个标签页（Ctrl+T），应该已经能看到动态视频背景了。

安装位置示意：

```
D:\EdgeVideoNewTab\
├── 一键安装.bat          ← 双击这个
├── 使用说明.md
└── extension\            ← 加载这个文件夹
    ├── manifest.json
    ├── newtab.html
    ├── css\  js\  icons\  media\
```

> ⚠️ 扩展加载后就"住"在这个文件夹里：**不要移动或删除 `extension` 文件夹**，否则下次打开 Edge 扩展会失效（重新加载后已添加的视频也可能丢失）。如果要换位置，请先移动，再到 `edge://extensions/` 重新加载。

## 二、换视频（三种方式）

| 方式 | 操作 |
| --- | --- |
| 本地视频（最常用） | 点击右上角 **⚙ 设置** → 「背景视频」→「**本地视频**」，选一个或多个视频文件；或直接把视频文件**拖到页面任意位置**（有虚线提示），松手即添加并设为背景 |
| 视频直链 | 设置 → 「**视频链接**」→ 粘贴以 `https://` 开头的视频直链（必须是能直接播放的视频文件地址，例如 `https://example.com/a.mp4`） |
| 轮换列表 | 添加多个视频后：用 ⚙ 面板里的「使用」切换；页面右上角会出现 ⏮ ⏭ 按钮；也可以打开「每次打开随机播放」或「自动轮换」 |

支持浏览器能播放的格式，**推荐 MP4（H.264 编码）或 WebM**。MKV / AVI / 部分 MOV、HEVC/H.265、杜比视界等格式 Edge 可能无法播放，需要先用工具转成 MP4(H.264)。

添加本地视频时，视频会被复制一份到 Edge 的扩展存储里（约等于原文件大小），所以：
- 建议单个视频 **不要超过 2GB**，否则保存可能失败；
- 在设置里点「删除」会同时删除这份存储副本，不会动你原来的视频文件；
- 想彻底清空：卸载扩展即可（见文末）。

## 三、设置面板说明

| 分组 | 选项 | 作用 |
| --- | --- | --- |
| 背景视频 | 本地视频 / 视频链接 / 拖放 | 添加、切换、删除背景视频 |
| 播放 | 静音、音量、循环、播放速度 | 控制声音与播放节奏。**受浏览器自动播放策略限制：带声音的视频通常要在点一下页面后才能出声**，所以默认静音 |
| 播放 | 画面填充 | 裁剪铺满（推荐）/ 完整显示 / 拉伸铺满 |
| 播放 | 亮度、模糊、暗色遮罩 | 调整视频观感，让桌面图标/文字更易读 |
| 切换 | 每次打开随机播放 | 每开一个新标签页随机选一个视频 |
| 切换 | 自动轮换 + 间隔 | 页面开着时每隔 N 分钟自动换下一个 |
| 搜索框玻璃 | 磨砂强度 / 玻璃浓度 / 边缘折射 / 镜片厚度 / 色散 | 搜索框玻璃由 WebGL 实时渲染（边缘折射、色散、雾化都是实时计算）。磨砂强度控制背景模糊，玻璃浓度控制通透度，边缘折射控制透镜扭曲强度，镜片厚度控制边缘折射环带宽度，色散控制边缘的彩色分离；拖动即时生效，都拖到 0 即完全透明 |
| 页面元素 | 时钟、日期、搜索框、搜索引擎 | 可随时隐藏，搜索引擎支持 Bing / 百度 / Google |
| 其他 | 恢复默认设置 | 只重置设置，不删除视频列表 |

**右上角快捷菜单**：新标签页右上角只有一个玻璃「≡」按钮，点开后是二级菜单（上一个视频 / 下一个视频 / 静音 / 设置），菜单和搜索框使用同一套 WebGL 液态玻璃材质；点空白处或按 `Esc` 收起。

**快捷键**：`Esc` 关闭二级菜单或设置面板；面板关闭时**直接打字**会进入搜索框；视频随时可以拖进页面替换。

## 四、常见问题

**Q：为什么没有声音？**
浏览器不允许网页"带声音自动播放"。默认静音是正常的，点右上角的声音按钮即可开启；如果设置里取消了静音，下次开新标签页仍可能被浏览器要求先点一下页面才能出声。

**Q：视频黑屏 / 提示无法播放？**
大概率是编码格式不受支持。用格式工厂、HandBrake 或 ffmpeg 转成 **MP4（H.264 + AAC）** 再添加即可。ffmpeg 示例：
`ffmpeg -i 原视频.mkv -c:v libx264 -crf 20 -c:a aac 输出.mp4`

**Q：想要原来 Edge 的新标签页怎么办？**
打开 `edge://extensions/`，关闭或移除「视频新标签页」扩展即可恢复。

**Q：怎么更新这个扩展？**
用新版本文件覆盖 `extension` 文件夹里的内容，然后到 `edge://extensions/` 点开「视频新标签页」卡片上的「重新加载」（🔄）按钮。设置和视频一般会保留。

**Q：换电脑 / 重装 Edge 后视频还在吗？**
扩展数据存在本机 Edge 用户配置里，不随文件移动。换电脑需要重新安装扩展并重新添加视频（配置文件可用 Edge 账号同步，但扩展本地数据不会同步）。

**Q：会不会上传我的视频或记录？**
不会。扩展没有任何联网代码，视频和设置只存在本机；从网络加载的只有你自己填写的视频直链。

**Q：可以隐藏搜索引擎、只用背景吗？**
可以，在「页面元素」里关掉时钟、日期、搜索框即可，版面就只剩视频背景。

## 五、卸载

1. 打开 `edge://extensions/`；
2. 找到「视频新标签页」，点击「移除」；
3. 删除 `D:\EdgeVideoNewTab` 文件夹即可（扩展存储会在卸载扩展时一并清除）。

---

## 六、给进阶用户

- 视频数据存放在扩展的 IndexedDB（`vnt-videos` 数据库）里；设置和视频列表在 `chrome.storage.local`（键名 `settings` / `videos` / `initialized`）。
- 想改默认效果：编辑 `js/app.js` 顶部的 `DEFAULT_SETTINGS`，或直接改 `css/style.css`；改完到 `edge://extensions/` 点「重新加载」。
- 示例背景视频是 `media/demo.mp4`（可删除，也可换成自己的视频）。
