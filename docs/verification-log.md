## 已知限制（非缺陷）

- Edge 原生只支持"图片"作为新标签页背景，视频背景必须通过扩展实现。
- 浏览器禁止带声音自动播放：默认静音播放，点右上角音量按钮可开启声音。
- 浏览器能播放的格式有限，推荐 MP4（H.264）或 WebM；MKV/AVI/HEVC 等需先转码。
- 本地视频会复制一份到 Edge 扩展存储（约等于原文件大小），建议单个不超过 2GB。
- 卸载扩展会一并清除已添加的视频数据。
