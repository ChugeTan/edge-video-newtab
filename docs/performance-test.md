# 性能测试记录

- 测试设备：AMD Radeon 780M 核显（WebGL 硬件加速，ANGLE Direct3D11）
- 测试方法：同一扩展页面，解除浏览器帧率上限（--disable-frame-rate-limit --disable-gpu-vsync）后测 4 秒 rAF 平均帧率；窗口 1280×820。
- 对比对象：新版 WebGL 实时玻璃 vs 关闭 WebGL 后的 CSS 滤镜回退方案（即旧版实现）。

| 场景 | WebGL 实时玻璃 | CSS 滤镜回退（旧版） |
| --- | --- | --- |
| 默认设置（磨砂 40 / 折射 65） | 328.9 fps（3.04 ms/帧） | 276.9 fps（3.61 ms/帧） |
| 最重设置（磨砂 80 / 折射 100 / 色散 100） | 154.2 fps（6.48 ms/帧） | 58.5 fps（17.11 ms/帧） |

结论：WebGL 实时渲染在两种场景下都**比旧的 CSS 滤镜方案更快**（默认约快 19%，最重设置约快 2.6 倍）；旧 CSS 方案在最重设置下已跌破 60fps，而 WebGL 版仍有大量余量。实际使用时渲染锁定 30fps、只渲染搜索框约 990×84 物理像素、标签页隐藏或视频暂停时停止渲染，开销很小。
